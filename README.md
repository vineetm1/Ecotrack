# EcoTrack - Carbon Footprint Awareness Platform

EcoTrack is a web application that helps users understand, track, and reduce their carbon footprint.

## Features

- Carbon Footprint Calculator
- Personalized Sustainability Suggestions
- Daily Eco Tips
- Progress Tracking Dashboard
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript

## Deployment

Hosted using GitHub Pages.
