🌍 CarbonSphere

Climate Intelligence & Carbon Footprint Awareness Platform

CarbonSphere is an interactive web platform that helps users calculate, analyze, and reduce their carbon footprint through intelligent sustainability insights and visual analytics.

🚀 Features

♻ Carbon Footprint Calculator

Calculate estimated carbon emissions based on:

- Electricity Usage
- Vehicle Travel
- LPG Consumption
- Air Travel

🌱 Eco Score System

Users receive a sustainability score based on their carbon footprint:

- Green Hero
- Eco Learner
- Carbon Aware
- Planet Protector

🌳 Tree Offset Calculator

Estimate the number of trees required to offset annual carbon emissions.

📈 Analytics Dashboard

Interactive carbon trend visualization using Chart.js.

🤖 EcoBot Assistant

Provides sustainability recommendations and environmental guidance.

🌍 Future Earth Simulator

Shows the potential environmental impact of current lifestyle choices.

💾 Local Storage Support

User results are saved locally for future visits.

🏆 Sustainability Challenges

Interactive eco-friendly challenges to encourage sustainable habits.
